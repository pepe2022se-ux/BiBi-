# ТЗ — BiBi 1.0 Investor Prototype

## Цель
Собрать связанный инвесторский PWA-прототип BiBi: цифровая история и сервисная система автомобиля от покупки до продажи. Главный объект — автомобиль/Vehicle ID. Дизайн — premium dark, высокая читаемость, neon-green акцент.

## Роли и режимы
- FREE: гараж, история, штрафы, страхование, Market, поиск помощи/СТО, AI demo.
- CARE: годовая сервисная программа, статус на автомобиле, льготная/включённая помощь по программе.
- В профиле — демонстрационный переключатель FREE/CARE.

## Главная
Автомобиль, Vehicle ID/VERIFIED, CARE status/upgrade, 4 действия: Помощь / СТО / Купить / Продать. Блок «Что важно сейчас»: штрафы, ОСАГО, ТО. Переход в VERIFIED Market.

## Помощь 24/7
Эвакуатор, запуск АКБ, колесо/шиномонтаж, топливо, мобильный механик, аварийный комиссар. Цепочка: услуга → адрес → автомобиль → исполнитель/цена → checkout → tracking.

## СТО
Автомобиль → проблема → 3 СТО → диагностика → электронная смета → согласование/отклонение → полная оплата или финансирование → запись в историю. Будущий этап: фото/видео, допработы, гарантия.

## Финансирование ремонта
Сумма сметы → срок → ориентировочный платёж → карточки банков → заявка. Все расчёты демо до реальных банковских API.

## Market
15+ объявлений разных марок и классов, фильтры/чипы, цена, год, пробег, VERIFIED. Все объявления — демонстрационные.

## VERIFIED
У каждого объявления уникальный отчёт: score прозрачности, владельцы, пробег, ДТП/страховые события, ремонты, ТО, диагностика, юридические/эксплуатационные сигналы. События не должны дублироваться между автомобилями. Не давать бинарный вердикт «хорошая/плохая машина».

## Проверка перед покупкой
VIN 990 ₽; СТО 5 900 ₽; выездная 8 900 ₽; Comprehensive 12 900 ₽ — демонстрационные цены. Checkout → отчёт.

## Продажа
Мой автомобиль → оценка → диагностика → обновление VERIFIED → объявление → отклики → сделка.

## Страхование
ОСАГО/КАСКО. Реальные названия страховщиков: АльфаСтрахование, Ингосстрах, ВСК, РЕСО-Гарантия, Росгосстрах, Согласие, Т-Страхование. Любые цены в прототипе явно помечать как демонстрационные до API.

## Автокредит
Карточка авто → стоимость → первоначальный взнос → срок 1–7 лет → ориентировочный платёж → предложения банков → заявка. Не выдавать демо-ставку за реальную оферту.

## Гараж / Vehicle ID
VIN, госномер, пробег, VERIFIED, документы, страхование, CARE, ТО/ремонты, расходы, финансы.

## BiBi AI Demo Engine
Локальный сценарный движок без LLM API. Должен понимать вариации стандартных запросов и запускать действия BiBi: Check Engine, эвакуатор, СТО, ремонт/рассрочка, штрафы, страхование, CARE, проверка VIN/VERIFIED, покупка, продажа, подбор авто, автокредит. Ответы используют демо-контекст Garage/Market.

## Checkout
Единый демо-экран оплаты (СБП/карта), без реального эквайринга. Успех переводит в следующий этап сценария.

## Технически
Static PWA: index.html + manifest + service worker + icons/assets. LocalStorage для режима FREE/CARE. Новый cache key на каждую релизную сборку.
