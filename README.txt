BiBi Web/PWA 0.3

Это installable web app (PWA).

Важно: чтобы iPhone предложил полноценный режим веб-приложения и service worker работал, файлы нужно разместить на HTTPS-хостинге. Открытие index.html как локального файла подходит только для просмотра.

После публикации:
1. Откройте адрес BiBi в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» / Add to Home Screen.
4. Запускайте BiBi с иконки.

Демо хранит состояние FREE/CARE локально на устройстве.
